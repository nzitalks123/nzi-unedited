NZI, UNEDITED — MULTI-POST BLOG
=================================

This is the upgraded version of the Nzi, Unedited website.

FILES
-----
index.html              Homepage
blog.html               Blog archive / post list
posts/                   Individual blog post pages

HOW TO ADD A NEW POST
---------------------
1. Copy one of the HTML files inside the posts/ folder.
2. Rename it, for example:
   my-new-post.html
3. Open it in a text editor (Notepad is fine).
4. Replace the title, date, category and paragraphs with your own post.
5. Save it inside the posts/ folder.
6. Open blog.html and copy one of the existing <article class="post-card"> blocks.
7. Change its title, date, description and href so it points to your new post.
8. If you want it on the homepage too, update the "Latest from Nzi" section in index.html.
9. Upload the changed/new files to GitHub.
10. Wait a few minutes for GitHub Pages to update.

IMPORTANT
---------
Keep the folder called "posts" and keep the files inside it.
Do not upload the ZIP file to GitHub. Upload the actual files/folders.

GITHUB PAGES
------------

SAFETY / PRIVACY
----------------
Because this is a public blog, avoid publishing your school name, home address,
phone number, passwords, private contact details, or other information that could
make it easy for strangers to locate or identify you offline.
